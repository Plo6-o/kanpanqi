# 交易看板 · BOE·A500

盘中盯盘 + 收盘复盘的一页式工具。

| 文件 | 作用 |
|---|---|
| `index.html` | **交易看板（网址根目录，手机打开就是这个）** |
| `dashboard.html` | 同上（旧链接兼容） |
| `archive.html` | 主档案：历史复盘、分析、事件日历 |
| `manifest.webmanifest` / `sw.js` | PWA：可「添加到主屏幕」、离线可开 |
| `icon-*.png` | 应用图标 |

## 隐私
持仓与复盘记录只保存在**你自己手机浏览器的 localStorage**，不上传服务器。
任何拿到本页的人看不到你的持仓数据。定期在「复盘 → 导出/备份」生成备份短码。

## 数据
行情来自腾讯行情接口 `https://qt.gtimg.cn`（实时快照，非 Level-2）。收盘后返回收盘价。
页面里的分析文字与价位为静态快照，需手动更新。
